# 云服务器部署指南（面向非技术操作者）

目标：一台常年在线的小服务器，让 AI 能自动「听到」企微群消息（回调）并常驻运行。
预算：约 ￥50–100/月。全程约 20 分钟。

## 第 1 步：买服务器

推荐 **腾讯云「轻量应用服务器」**（阿里云轻量同理）：

1. 打开 cloud.tencent.com → 产品 → 轻量应用服务器 → 立即选购
2. 地域：**上海 / 广州**（境内，企微回调延迟低；勿选境外）
3. 镜像：**Ubuntu 22.04 LTS**（或 24.04）
4. 套餐：最低配即可（2核2G 足够）
5. 购买后在控制台记下 **公网 IP**

## 第 2 步：放行 80 端口

轻量服务器控制台 → 该实例 → 防火墙 → 添加规则：允许 **TCP 80**（HTTP）。

## 第 3 步：一键部署

轻量服务器控制台 → 该实例 → 点 **「登录」**（浏览器里会打开一个黑色终端窗口，
默认 root 用户）→ 把准备好的部署命令**整段粘贴**进去回车（命令由维护者提供，
含企微凭据；模板见 `scripts/deploy.sh` 头部注释）。

脚本会自动完成：装依赖 → 拉代码 → 生成配置 → 注册常驻服务（开机自启、崩溃自动拉起）。
结束时屏幕会打印**企微后台要填的三个值**（回调 URL / Token / EncodingAESKey）
和**可信 IP**、**控制台访问令牌**。把这段输出完整复制保存。

## 第 4 步：企微后台回填（电脑）

work.weixin.qq.com → 应用管理 → 自建 → 进入应用：

1. **接收消息** → 设置 API 接收：粘贴脚本输出的 URL / Token / EncodingAESKey → 保存
   （保存时企微会访问服务器做验证，服务在跑就会通过）
2. **企业可信IP** → 配置：填服务器公网 IP → 保存

## 第 5 步：验证

浏览器访问 `http://服务器IP/health`，看到 `{"ok":true,"mode":"shadow"}` 即部署成功。
之后把控制台访问令牌交给维护者，由维护者远程完成群档案绑定与影子模式验证。

## 日常维护

| 操作 | 命令（服务器终端） |
|---|---|
| 看服务状态 | `systemctl status responder` |
| 看实时日志 | `journalctl -u responder -f` |
| 重启服务 | `systemctl restart responder` |
| 升级到最新代码 | 重新粘贴部署命令即可（幂等，配置不会被覆盖） |
| 手动备份数据库 | `/usr/local/bin/responder-backup`（每天 03:30 自动跑，存 `/opt/pe-backups/`，保留 30 天） |

## 安全须知

- `.env`（含全部密钥）只存在服务器上，权限 600，不入代码库
- 控制台与 `/ingest` 由 `X-Admin-Token` 保护；企微回调路由由消息签名保护
- 上线稳定后建议：轮换企微 Secret 与 DeepSeek key、把服务器 SSH 改为密钥登录

## 访问令牌

默认由 `deploy.sh` 随机生成。律所侧可在控制台「状态」面板 →「修改访问令牌」
改成一句记得住的话（如 `qingchen-6-lubiao`）。

允许用短语而不是坚持随机字符，是因为随机字符最后一定会被抄进某个记事本或
聊天记录里，反而更不安全。前提是服务端有**连续输错锁定**：同一 IP 15 分钟内
最多 8 次，之后一律 429（正确令牌在锁定期内同样被挡，否则攻击者可以靠
「哪个不报 429」反推）。有这道闸，十二位的短语在线上已经猜不动了。

两条底线不让步：

- **不能取消。** 这台机器在公网上，控制台里是全部客户咨询的原文（PIPL 敏感），
  而「升级」按钮等于在服务器上执行代码。
- **不能用律所名 + 数字**（`songhu123` 之类）。域名就是 songhulaw，
  那是攻击者会试的第一个。

免输入登录：状态面板可复制 `.../ui#t=<令牌>` 存成书签，点一下直接进。
令牌放在 `#` 片段里而不是 `?` 查询串，因此不会随请求发到服务器、不进访问日志。
**这条链接等同于密码。**

## 运维指令（两边够不着时的通道）

律所侧没有 SSH，运维侧出网受组织策略限制够不着这台服务器——两边都到不了对方。
但**服务器够得着 GitHub**。代码升级已经靠这个方向解决了，运维动作同理：

```
提交 ops/commands.json  →  服务器下一轮（≤5 分钟）执行  →  结果发到管理员企业微信
```

指令名走白名单（`responder/opscmd.py` 里的 `_op_*`），参数不进 shell。
这不扩大任何权限：服务器**本来就**在自动执行这个分支上的代码，
一份声明式清单严格弱于那个能力。

`id` 是幂等键，执行过永不再执行——自动升级每 5 分钟拉一次，
少了它，一条「重置令牌」会每五分钟重置一次。**不要复用旧 id。**

⚠️ **仓库是公开的，指令文件里绝不能出现密钥。** 所以 `reset_admin_token`
不接受指定值：由服务器随机生成，只走企微私信送到人手上。

现有指令：

| op | 作用 |
|---|---|
| `report` | 汇报运行模式、进线事件数、名册规模、对外地址 |
| `reset_admin_token` | 重置控制台令牌，私信新令牌 + 免输入登录链接 |
| `add_kf_servicers` | 把名册律师加为客服接待人（会话转接的硬前置） |
