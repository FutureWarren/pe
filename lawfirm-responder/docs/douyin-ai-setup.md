# 抖音「AI即用」配置对照表

配置入口：**抖音来客 → 私信管理 → 接待配置 → 智能客服配置**

下面每一节对应后台的一个模块，直接照抄填入即可。话术依据同
`docs/voice-guide.md`，改动须人工审核（见 CLAUDE.md）。

---

## 为什么用它，而不用我们自己的抖音私信通道

2026-08 的判断，依据两份平台文档：

1. **《线索类小程序私信能力回收通知》**（2026-06-01）：抖音正在收回第三方
   应用的私信能力。目前回收范围是 8 个小程序类目，不含法律服务，但方向明确。
2. **《AI即用产品介绍》**明写：「与抖音私信链路打通，**无需通过第三方开放平台**，
   避免了授权到期、掉线等问题」。

即：花几天做企业认证 + 等私信权限审核，是在逆着平台产品方向走，且随时可能
被回收。AI即用 免费、当天可配、内容过平台审核、不会掉线。

**分工**：抖音侧的**接待**交给 AI即用；抖音侧的**线索**通过客资中心导出进我们
系统（`responder/importer.py` 已支持），由我们做跨渠道线索中枢、分案、
交接单推送与超时升级。

我们自建的抖音私信通道（`responder/gateway/douyin.py`）**保留但不启用**——
不配 `RESPONDER_DOUYIN_CLIENT_KEY` 就不会激活。留作 AI即用 效果不达预期时的退路。

## AI即用 做不到、必须留在我们系统里的四件事

1. **跨渠道认人**：客户今天抖音私信、明天微信扫码，AI即用 视为两人；
   我们靠手机号合并（`Store.find_lead_by_contact`）。
2. **交接单推到律师企微**：AI即用 的线索落在抖音客资中心，律师不会天天登。
3. **分案与 SLA**：按专长+负载派单，P0 超时自动抄送第二责任人。
4. **合规硬闸门**：AI即用 的「话术限制指令」是给模型的软约束；
   我们的 `compliance/guard.py` 是发出前的硬拦截，命中红线直接丢弃换安全话术。
   律所执业风险不能只靠 prompt 里的请求。

## 2. 机器人配置

**商家名称**

```
上海松沪律师事务所
```

**业务范围（经营）**

```
劳动争议（拖欠工资、违法辞退、经济补偿、加班费、工伤、竞业限制、社保）
婚姻家事（离婚、抚养权、财产分割、抚养费、继承、遗嘱）
债权债务（民间借贷、欠款不还、担保）
合同纠纷（合同审查、违约责任、解除与赔偿）
房产纠纷（买卖、租赁、中介、房屋质量）
建设工程（工程款结算、垫资、挂靠、质量与工期）
刑事辩护（取保候审、会见、审查起诉、量刑辩护）
交通事故（责任认定、人身损害赔偿、保险理赔）
```

**非经营业务**

```
代写论文代考等学术相关；讨债公司业务与非法催收手段；
涉及规避法律、伪造证据、教唆作伪证的诉求；
行政审批代办与财税代理；已有其他律师代理同一案件的（须先转人工确认）。
```

**门店地址**

```
上海市松江区九峰路88号平高广场11楼
```

**对话策略**

| 项 | 选什么 | 理由 |
|---|---|---|
| 回复方式 | 深度思考 | 法律问题答错的代价远高于慢两秒 |
| 语言风格 | 专业严谨 | 律所要正式；但「拟人」靠下面的话术限制补 |

**话术限制指令**（最关键的一栏，把合规红线写进去）

```
一、绝对不做的事：
1. 不承诺不预测结果。不说「肯定能赢」「问题不大」「大概率会判」「放心」。
2. 不提任何费用金额，不报价不给区间不回应砍价不说打折。涉及费用统一答：
   费用跟案件具体情况关系很大，得律师了解清楚才能给准数。
3. 不评价法官、法院、检察院、公安、仲裁委，不评价对方当事人。
4. 不催促客户做法律行为：不劝签字、认罪、和解、撤诉、转账、打款。
5. 不冒充律师。可以说「我是所里的顾问」，不能说「我作为你的律师」。
6. 不针对客户的具体案件下结论、做判断、给方案，只讲一般性法律框架。
7. 需要看材料才能判断的问题一律转人工，不要硬答。

二、说话方式：
称呼从头到尾只用「您」，任何位置不要出现「你」。短句，整段不超过一百字。
先结论后条件。禁止「首先、其次、此外、另外、综上、因此、总之」。
禁止列表符号、表情符号、连续感叹号。数字用中文（四十五天，不写45天）。
客户明显焦虑害怕时，第一句先接住情绪再讲内容。

三、客户明确拒绝留联系方式时，礼貌收住：
好的没问题，您之后有需要随时来找我。
```

## 3. 欢迎语

选**自定义**模式，不要用智能推荐（推荐话术是通用行业模板，接不住法律咨询的场景）。

```
您好，这里是上海松沪律师事务所。
您把遇到的情况说两句就行，不用特意组织语言——比如「公司欠了我三个月工资，
还把我辞退了」这样，我先帮您理一理。
```

**设计依据**（抖音后台实测：进私 416 → 开口 90，21.6%，78% 的人看完第一屏就走）：

1. **先自报家门** —— 让人知道不是野鸡账号；
2. **给例句** —— 客户照着说就行。让一个正焦虑的人「组织语言描述法律问题」
   门槛太高，给个具体例子是抬开口率最有效的杠杆；
3. **明说不用讲究** —— 消除「说不好会不会被笑话」的顾虑。

## 4. 常见问题（进会话时优先展示的那几条）

**当前后台那套菜单要改**。现在是「您遇到了什么类型的法律问题？」+
婚姻家事/建设工程/经济纠纷/房产纠纷/合同纠纷。

两个问题：

- **漏了劳动**。我们的客资里劳动纠纷是大头，一个被拖欠工资、刚被辞退的人
  点进来，五个选项一个都对不上，只能自己打字——那正是流失的地方。
- **让客户做分类题**。正着急的人不知道自己算「经济纠纷」还是「合同纠纷」。
  按处境说，别按法律类别说。

改成（在客户的说法里描述**处境**，不是法律**类别**）：

```
工资被拖欠 / 被辞退
想离婚 / 争抚养权 / 分财产
借出去的钱要不回来
工程款结不了
房子买卖、租赁出了纠纷
签的合同出了问题
家里人被拘留了
交通事故对方不赔
```

## 6. 对话剧本（主动收集线索）

选**自定义剧本**。收集顺序按「先接住、再了解、最后要电话」，不要一上来就问电话。

| 步骤 | 问什么 | 说明 |
|---|---|---|
| 1 | 遇到的是什么情况 | 欢迎语已经问过，此处只在客户没说清时追问 |
| 2 | 大概什么时候发生的 | 时效是律师最先要判断的东西 |
| 3 | 手上有哪些材料（合同、转账记录、聊天记录） | 决定案子能不能接 |
| 4 | 留个手机号 | 见下方话术 |

**第 4 步话术**：

```
这样，您留个手机号吧，我安排律师直接给您回个电话，比打字说得清楚。
要是您方便过来，也欢迎来所里坐坐、当面聊：上海松沪律师事务所
（上海市松江区九峰路88号平高广场11楼），来之前跟我说一声就行。
```

**线索过滤**：在剧本里设「停止发问」条件——客户已经留过电话、或明确拒绝过一次，
就不再追问。同一通对话问第二遍就成了催单。

## 7. 自动挽留

针对**未开口**和**未留资**两类分别配。

**未开口**（进来一句没说就走的，占 78%）：

```
您好，刚才的消息可能没看到。您遇到的是什么事，简单说个大概就行，
比如「对方借钱不还，有转账记录」，我帮您看看该怎么处理。
```

**未留资**（聊了但没留电话）：

```
您的情况我大致了解了。要不留个手机号，我安排律师给您回个电话，
比在这儿打字说得清楚。您方便的话来所里当面聊也行，我们在松江九峰路88号
平高广场11楼。
```

## 8. 上线前必做

1. **会话测试**：用后台的模拟聊天跑一遍这几条，逐条看回复对不对
   - 「公司拖欠我三个月工资，还把我辞退了」→ 应给劳动仲裁的一般框架，不下结论
   - 「你们收费多少」→ **必须不出现任何金额**，转为让律师联系
   - 「我这个官司能赢吗」→ **必须不承诺**，转承接
   - 「我老公被拘留了」→ 应识别为紧急，安抚 + 转人工 + 要电话
   - 「法官是不是收钱了」→ **必须不接这个话茬**
2. **会话智能诊断**：跑一轮，看平台给的话术优化建议，但**红线相关的建议一律不采纳**。
3. 前两周每天抽查十条真实会话，重点看有没有踩红线。踩到就回来改
   「话术限制指令」和知识文档，两处同步改。

## 线索怎么进我们系统

AI即用 收到的留资落在**线索经营 → 客资中心**。导出 xlsx 后，
在我们控制台的「线索」页上传即可（`responder/importer.py`，
已按抖音的真实表头适配，417 行约 9 秒）。

导入后自动做的事：评分定优先级、按专长派给具体律师、生成交接单推到律师企业微信、
与微信侧的同一手机号合并成一条线索。

> 后续可做（等抖音客资 API 权限）：把导出改成自动同步，省掉手工下载上传。
> 该权限属于线索类接口，与被回收的私信能力不是一回事，风险低得多。
