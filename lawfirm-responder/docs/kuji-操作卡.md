# 酷机时代 · 操作卡（给操作的人看，不是给工程师看）

> 今天只要回答一个问题：**客户在公众号里发的消息，我们收不收得到。**
> 收得到 → 后面全是填空题。收不到 → 方案要换（找云盛），越早知道越好。
> 其余所有事（话术、库存、订单、正式上线）都排在这个答案之后。

---

## 你手上的三个值

| 名称 | 值 |
|---|---|
| 回调地址（URL） | `https://responder-production.up.railway.app/mp/callback` |
| 令牌（Token） | `SYHWOmU4GM8nA3xfprq9PIFWuZBo` |
| 消息加解密方式 | **明文模式** |

> 这台是**临时测试机**（Railway，免费，随时可删）。它只用来回答上面那一个问题。
> 正式上线要换成境内服务器（见 `docs/deploy.md`）——原因不是省钱，是
> **发消息要用固定出口 IP**（公众号的 IP 白名单），而这类平台的出口 IP 不固定。
> 收消息不受这个限制，所以拿它验「收不收得到」正好。

---

## 第 1 步：先看一眼「自动回复」（2 分钟）

电脑打开 **mp.weixin.qq.com**（微信公众平台，**不是**你之前开的开发者平台），
用公众号管理员身份登录 → 左侧 **内容与互动 → 自动回复**
（旧版在 **功能 → 自动回复**）。

- **里面有内容** → 截图存下来。这几句是门店在用的话术，第 2 步会让它们失效，
  要搬到我们这边接着发。
- **打不开 / 提示不可用 / 是空的** → 说明早就没在用了，直接往下走。

顺手把**关键词回复**那一页也截下来——门店自己总结的高频问题就在那儿，
那是话术表最好的第一版。

---

## 第 2 步：填回调地址（5 分钟）

还在 mp.weixin.qq.com：**设置与开发 → 基本配置 → 服务器配置 → 修改配置**

1. **服务器地址(URL)**：粘上面那个 URL
2. **令牌(Token)**：粘上面那个 Token
3. **消息加解密密钥**：点「随机生成」（我们用明文模式，这个值填了不用）
4. **消息加解密方式**：选 **明文模式**
5. 点**提交**

提交时微信会当场访问一次那个地址做验证：

- **提示成功** → 记得点一下**「启用」**（有的版本提交后是停用状态）
- **提示 token 验证失败** → 多半是网络慢超时了，**再点一次提交**。
  连试三次还不行再找我。

> ⚠️ 这一步**不会影响云盛和会员云**。他们走的是第三方平台授权，跟这里的
> 服务器配置是两条路。真出问题，把这里的配置删掉就完全恢复原样。

---

## 第 3 步：发一句话试试（1 分钟）

用**你自己的微信**关注「酷机时代」这个公众号，然后在里面发一句：

```
保修多久
```

（随便什么都行，发一句就够。不用等回复——现在是影子模式，**故意不回**，
先看它会说什么。）

---

## 第 4 步：看通没通（30 秒）

手机或电脑浏览器打开：

```
https://responder-production.up.railway.app/health
```

找 `"mp_callbacks"` 这个数字：

| 看到什么 | 意思 | 下一步 |
|---|---|---|
| **大于 0** | ✅ **通了。** 消息真的到我们这儿了 | 走「通了之后」那一节 |
| **一直是 0** | 消息被推给了云盛/会员云，我们收不到 | 走「没通之后」那一节 |

（每发一句话这个数字加一。多发几句确认不是巧合。）

---

## 通了之后（按顺序，不着急）

1. **填话术**——三条必须门店自己定：门店地址与营业时间、正品行货的对外口径、
   支持哪些付款方式。另外六条有默认值也要过一遍（「进水算不算保修」这种
   各家做法不同）。
2. **建企微群 + 群机器人**——群设置 → 群机器人 → 添加 → 复制 Webhook。
   五分钟，不需要管理员审批。**AI 答不了的客户会推到这个群**，
   不配的话那些人就没人管了。
3. **换成境内服务器**——见 `docs/deploy.md`，顺便把公众号的
   AppSecret 和 IP 白名单配上（发消息要用）。
4. **影子模式跑一周**，看它会说什么，再决定让不让它说。

## 没通之后

别急着解绑云盛——**不用解绑**（两家平台同时持有「消息管理」，说明可以并存）。
两条路：

1. **打电话问云盛**：能不能把公众号消息转发一份给我们。他们的久惠宝设置里
   有「客服列表」，说明产品内建客服能力，很可能现成就有。
2. **我们自己注册成第三方平台**并列授权。微信开放平台认证 300 元 + 审核，
   几天到两周。零解绑、零风险，只是慢。

---

## 想撤掉这台测试机

Railway 控制台 → 项目 `kuji-wechat-ai` → Settings → Delete。
公众号那边把服务器配置删掉即可。两边都不留痕迹。
